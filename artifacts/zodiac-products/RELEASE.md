# Zodiac square product mockups

Completed 10 October 2026. Twelve separate square mockups of matte-black sheet-metal plaques on a clean white wall, using the supplied Tabler glyph and constellation SVGs as references.

The images are **generated product visualizations**, not photographs of manufactured zodiac samples or approved CAD. The original source SVGs remain unchanged.

All images are **1254 × 1254 pixels (1:1)**. Use the WebP copies for web pages; PNGs are the retained masters. No storefront code or live product listings were changed.
